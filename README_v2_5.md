# WAKE辞典 v2.5 — 組み合わせランキング / 女子フィルター / 当日取得耐障害化

## ランキング

- 伏兵（1着率の級別基準差）
- 紐推し（3連対率）
- まくり、まくり差し、差し
- イン最強、イン不安定
- ダッシュ巧者
- スタート巧者、Fなし

すべてのランキングで、全級・A級・B級・A1・A2・B1・B2を選択できます。
コースはランキング既定、全コース、1〜6の単独、3〜6、4〜6を選べます。

以下は同時に組み合わせ可能です。

- 級別
- コース
- 女子選手のみ
- 本日の女子戦 / 男女混合戦
- 本日出走のみ
- 出走場
- 全場成績 / 選択場成績
- 最低走数
- 補正ON / OFF

女子選手はBOAT RACE女子レーサー名鑑から日次更新します。取得先の一時障害時は、
コミット済みの直近正常名簿を使います。

「女子戦 / 男女混合戦」は本日の出走表の6艇構成から判定します。
ランキングに使う過去成績は従来どおり直近24か月です。

## 当日出走表

BOATCASTの公開遅延に備えて、10分間隔・最大75分のprobe再試行を追加しました。
最後に24場の1R・6R・12Rを確認し、反応した開催場だけ全12Rを取得します。
それでも未公開の場合は `status=unavailable` を生成し、
本日フィルターだけを無効化して辞書本体のデプロイは継続します。

HTTPステータス別の失敗件数を `fetch_errors` とActionsログへ残します。
